# Katja Koch Kitas – Websites

Websites der vier Kitas Schatzkiste, Blumenwiese, Baumhaus und Kinderhaus.

**Stack:** Next.js 15 · Tailwind CSS · Sanity (Projekt „Katja Koch Kitas“) · Supabase (Projekt `katja-koch-kitas`) · Vercel

## Lokal starten

```bash
cp .env.example .env.local   # Werte aus Vercel eintragen (oder: vercel env pull .env.local)
npm install
npm run dev
```
